# Orbital Overlap: Bonding Theories (CHEM 1A · 1B)

Study game for OpenStax Chemistry 2e Chapter 8 (§8.1–8.4: valence bond theory, hybridization, σ and π bonds, molecular orbital theory), with §7.6 VSEPR as the on-ramp. Live at https://itsdrdan.github.io/bondingtheories/

Current version: v4

- `index.html`: the whole game (standalone; no build step). Loads the brand kit (`games/brand/itsdrdan.css`, `icons.js`, `embed.js`) and `games/track.js` for anonymous stats.
- 4 tiles students can mix: Overlap Basics, Hybrid Workshop, Sigma & Pi, MO Builder. Modes: Learn (Professor Tips + worked examples), Practice, Challenge (10 mixed, no hints).
- `?course=1A` (default) or `?course=1B`.
- Also: Daily 5, Skill Check Prep (typed answers) and the Theory Face-Off boss round. Direct links: `?mode=daily`, `?mode=skill`, `?mode=challenge`, `?mode=faceoff`.
- `INSTRUCTORS.md`: instructor notes, sources, slip catalog and the build plan.
- `ASSETS.md`: the art list (mascot Pip, logo, tile icons, badges). Stand-ins show until the files exist in `assets/`.
