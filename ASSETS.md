# Orbital Overlap (Bonding Theories): art

**Status (Nov 11, 2026):** all 29 images are in (ChatGPT set, checked: right names and sizes, transparent WebP, phase colors match the game). The study hub card image `games/assets/games/bondingtheories.webp` goes in the games repo.

**29 images total: 1 logo + 5 mascot moods + 4 tile icons + 3 mode cards + 16 achievement badges** (+ a copy of the logo for the study hub card).

Use the brand prompt from itsdrdan.github.io/games/brand and change only the Subject line. Glossy-but-flat cartoon style, thick dark-navy outlines, transparent background, **no text** except the letters or symbols listed.

**Two phase colors run through the whole game. Use them everywhere an orbital lobe appears:**
- **Blue lobe** #8fb8f0 with outline #346cc3
- **Coral lobe** #f6a99a with outline #bf5266

A p orbital is always one blue lobe + one coral lobe. An s orbital is a single blue sphere.

**Don't make:** molecule drawings, Lewis structures, wedge-and-dash sketches, MO energy diagrams, orbital boxes, the energy curve, the overlap and MO pictures, or the O₂-and-magnet picture. The game draws all of these with code because students tap on them and the chemistry has to be exact.

## The mascot: Pip the p orbital (5 moods)

Pip is a cute **p orbital standing upright**: a rounder **blue top lobe** (his head and body) and a slightly smaller **coral bottom lobe** (his "skirt"/legs), meeting at a narrow waist. Through the waist runs a thin dashed line: the **node**, like a little belt. Big dark eyes and rosy cheeks on the blue lobe, two tiny stubby arms. (The game's stand-in drawing already looks like this.) The name "Pip" is a placeholder; rename him if you like.

Make all five on one sheet so he looks identical in each. Cut each to **320 × 320 transparent WebP**.
